\section{Special Ext2 Filesystem Attributes}

Several trojanized executables were hardened with special Ext2 filesystem attributes to prevent modification or deletion, even by \texttt{root}:
\begin{itemize}
    \item \textbf{Immutable Attribute (\texttt{+i}):} Prohibits the file from being modified, renamed, deleted, or truncated. It can only be cleared by explicitly stripping the attribute via \texttt{chattr -i}.
    \item \textbf{Append-Only Attribute (\texttt{+a}):} Restricts write operations strictly to appending data to the end of the file, preventing existing content from being overwritten or zeroed out.
\end{itemize}
